# VatBrain Logo 设计说明

## 目标

为 VatBrain 的 GitHub README 和项目主页设计一组可对比的品牌 Logo。Logo 需要清楚传达
“缸中之脑”与 AI Agent 记忆增强的核心概念，同时保持项目级开源工具应有的辨识度和专业感。

## 统一品牌骨架

- 形式：横向“图形标 + `VatBrain` 英文字标”。
- 使用场景：GitHub README 顶部与项目主页。
- 背景：浅色、干净、无纹理，便于直接展示和后续抠图。
- 主色：深海蓝、神经紫、营养液青绿；三版保持同一色彩家族。
- 字标：现代几何无衬线字体，字距适中；文字仅出现一次，必须准确拼写为 `VatBrain`。
- 共同语义：培养容器代表 Vat，脑或神经网络代表 Brain；节点和连线暗示图与向量复合记忆。
- 禁止项：写实器官、血腥感、普通灯泡图标、密集小字、标语、水印、复杂场景背景。

## 方案 A：极简科技感

圆角培养皿或抽象容器构成外轮廓，内部用少量连续线条形成左右脑。脑沟同时表现为图节点和
向量轨迹。图形使用简洁几何面与克制渐变，缩小后仍能保持轮廓和识别度。

优势是 Logo 属性最强、适配范围最广，推荐作为后续主品牌方向。

## 方案 B：神经生物感

半透明容器中悬浮一组有机神经网络，关键突触节点隐约形成字母 `V`。强调关联检索、记忆
形成和神经可塑性，同时控制节点数量，避免成为科学插画。

优势是产品机制表达更直接；代价是小尺寸下部分神经细节会损失。

## 方案 C：赛博科幻感

发光脑核置于圆柱形生命维持舱，少量图谱连线从脑核向外延伸。使用深蓝、紫与青绿霓虹光，
但保持浅色背景和独立 Logo 构图，不扩展成完整海报或场景插画。

优势是视觉冲击和“缸中之脑”叙事最强；代价是通用性略低于极简方案。

## 交付物

- 三张独立的高分辨率 PNG 对比稿，每张只包含一个方案。
- 文件保存到 `assets/logo/`，采用稳定名称：
  - `vatbrain-logo-minimal.png`
  - `vatbrain-logo-neural.png`
  - `vatbrain-logo-cyberpunk.png`
- 三张图采用相近画布比例、字标大小和视觉占比，方便横向公平比较。
- 本轮只生成候选稿，不修改 README，不替换项目中的其他资产。

## 验收标准

1. `VatBrain` 拼写准确且只出现一次，无额外文字或水印。
2. 一眼可识别出“容器 + 脑/神经网络”两层含义。
3. 三版风格差异明显，但配色和字标保持品牌家族一致。
4. 在 README 常见显示宽度下，图形轮廓与字标仍清楚。
5. 构图四周留有安全边距，背景干净，便于后续制作透明版或 SVG 精修版。

## 本轮范围外

- 矢量 SVG 重绘、透明背景精修、favicon 与应用图标适配。
- README 接入、暗色主题变体、品牌字体授权与完整品牌规范。
- 在用户选定主方向前继续扩展更多变体。
