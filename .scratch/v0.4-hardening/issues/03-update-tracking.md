# 03 — Update Tracking(信息更新 → 旧记忆显式废弃/合并)

**What to build:** 当同一实体/主题出现时间上更新的新信息时,系统不再让新旧记忆并存竞争——旧记忆显式标记废弃或降权,新记忆权重提升,使"信息更新后的状态跟踪"可验证(HaluMem Dynamic Update 从 28.9% 显著提升)。复用既有冲突检测(极性+相似度)与再巩固(相似合并)能力,不新建并列机制。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 更新检测:同实体新信息判定"时间上更新"(覆盖旧状态),可复用冲突判定作为语义基础
- [ ] 生效动作:旧记忆标记 obsolete / 降权,新记忆权重提升;动作可解释、可追溯
- [ ] 接口:通过既有 MCP/API 暴露更新信号(自动检测或显式信号)
- [ ] 回归:单元测试覆盖更新判定、废弃/提升动作、幂等;评测验证在 06 收口
